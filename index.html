TRADO

Private Salesforce integration

TRADO is a private tool used by its developer to run a personal Salesforce org. It connects to the developer's own Gmail account through Google's official OAuth sign-in so that Salesforce can send automated notification emails (for example, daily login reminders and status summaries) to a small, known group of recipients.

What it does

  • Sends notification emails from the developer's own Gmail account via the Gmail API.
  • Does not read, store or analyse anyone's mailbox.
  • Is not offered to the public and has no sign-up.
